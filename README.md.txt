This project analyzes an employee dataset of ABC company to explore workforce distribution, salary trends, and demographic patterns. 
Use Python for data preprocessing, statistical analysis, and visualization in this project.
**Tools used in this project is:**
Python, Pandas, NumPy, Matplotlib, Seaborn.

**Preprocessing**

Imported dataset from ABC Company.xlsx.

Cleaned null values and ensured data integrity.

Replaced inconsistent Height column values with random integers between 150–180 cm.

Exported cleaned dataset to cleaned_data.csv.

**Analysis Tasks**

Team Distribution – Counted employees in each team and calculated percentage splits.

Position Segregation – Grouped employees by position to understand workforce composition.

Age Group Identification – Categorized employees into age groups.

Salary Expenditure – Found teams and positions with the highest total salary.

Correlation b/w age and salary – Checked relationship between age and salary.

**Visualizations**

Countplot – Employee distribution across teams.

Bar Chart – Employee count by position.

Pie Chart – Age group distribution.

Bar Chart – Salary expenditure by team & position.

Scatter Plot + Heatmap – Correlation between age and salary.
